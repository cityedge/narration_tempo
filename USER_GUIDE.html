1. このアプリでできること

Narration Tempoは、長尺ナレーションの前半と後半などの音量差を整え、声の高さを保ちながら話す速さを調整し、WAV／MP3へ保存するアプリです。EMSの基本的なレベラーの考え方を参考に、新しく実装しています。EMS全体の機能や処理結果を完全再現するものではありません。

作業は「読み込み → 必要な設定 → 部分試聴 → 全体変換 → 完成音声の確認 → 保存」の順で進めます。部分試聴は省略できます。全体変換と保存は別の操作です。

元ファイルは書き換えません。やり直すときも原音から処理するため、前回の結果に補正を重ね掛けすることはありません。バッチ、無音削除、録音、編集点の挿入、設定の永続保存はありません。

2. 起動・動作環境・プライバシー

利用者向けZIPをすべて展開し、index.htmlをChromeで開いてください。アプリ本体は単一HTMLで、利用時のインストール、ローカルサーバー、Python、Node.jsは不要です。検証にはChromiumを使用しています。他のブラウザではデコードや再生の対応が異なることがあります。

GitHub Pagesから開くこともできます。ページの取得には通信が必要ですが、音声の読み込み・解析・変換・保存はブラウザ内で行い、音声ファイルをサーバーに送りません。ローカル版はオフラインで使用できます。

画面右上の日本語／Englishで表示言語を変更できます。各操作項目にマウスを重ねると簡単な説明が表示され、ヒントも言語に連動します。タッチ操作ではマウスオーバーを利用できないため、本書を参照してください。右上の「マニュアル」で本書を別タブに開けます。単一HTMLだけを移動すると添付マニュアルへのリンクは開けなくなるため、配布フォルダ全体を保管してください。

ページを再読み込みしたり閉じたりすると、読み込んだ音声、設定変更、保持した処理結果は失われます。残したい結果は先に保存してください。

3. 最初の1本を仕上げる

1. 左上のファイル選択欄をクリック、またはWAV／MP3をドロップします。右上の進捗が完了するまで待ちます。

2. 「音声全体」で原音を再生し、波形やシークバーで気になる場所へ移動します。

3. レベラーはON、速度は1.000倍、音声補正3種類はOFFが初期状態です。音量だけ整えるなら、そのまま使えます。

4. 速さを変える場合は倍率を入力します。例えば1.200倍なら60分の音声が約50分になります。

5. 必要なら「30秒プレビュー」を展開し、開始位置を選んでボタンを押します。完成するとB（処理後）が自動再生されます。A／Bで比較してください。

6. 設定が決まったら「全体変換」を押します。完成音声をアプリに保持します。この操作ではダウンロードしません。

7. 「音声全体」で原音／処理後を切り替え、前半・後半・声が大きい場所・小さい場所などを確認します。

8. 出力形式を選んで保存ボタンを押します。保存先と確認ダイアログはブラウザのダウンロード設定に従います。

4. 画面上部：読み込みとステータス

入力欄にはファイル名、長さ、サンプルレート、チャンネル数、サイズを表示します。音声は一度に1ファイルです。別ファイルを読み込むと現在の結果は置き換わります。

ステータス欄には解析・変換・保存の段階、進捗率、エラーを表示します。進捗は処理段階に応じて更新され、残り時間を保証するものではありません。「中止」は処理の区切りで反映されるため、押した瞬間に終了しない場合があります。MP3のブラウザデコード自体は途中停止できず、中止後に得られた結果を破棄します。

5. 音声全体：再生・シーク・差分波形

「原音」は入力そのもの、「処理後」は全体変換した完成音声です。全体変換前は「処理後」を選択できません。プレビューだけを作っても、この全体再生は有効になりません。

再生ボタンは再生／一時停止を切り替えます。停止ボタンは、再生を開始した位置へ戻します。波形をクリック・ドラッグするか、下のシークバーで位置を変えられます。波形にフォーカスがあるときは左右キーで5秒移動、Homeで先頭、Endで末尾へ移動します。

原音／処理後の切り替えでは倍率を使って発話位置を対応させます。例えば1.2倍の処理後10秒は原音12秒に対応します。WSOLAは波形のつなぎ位置を局所的に調整するため、サンプル単位の厳密な同期を保証するものではありません。

全体変換後の波形は、対応する発話位置の振幅包絡を比較したものです。

色意味
グレー原音と処理後に共通する振幅領域
緑原音より大きくなった領域
赤原音より小さくなった領域

これは音声信号を引き算した差分音や、周波数スペクトラムではありません。また、振幅が同じでも聴感上の音量は異なる場合があります。最終判断は再生して行ってください。

6. レベラー：時間方向の音量差を整える

「レベラー（音量を自動で整える）」は、前半は大きく後半は小さい、といった音量推移を緩やかに補正します。初期ONで、細かな調整項目はありません。瞬間ごとにすべてを同じ大きさへ揃える処理ではなく、声の抑揚をある程度残します。

基本処理は、0.5秒のピーク解析窓を0.1秒間隔で評価し、−6 dBFSを基準にゲインカーブを作るものです。増幅は最大＋6 dB、減衰は最大−24 dB。4秒のトゲ除去、4秒のメディアン、12秒の平滑化、毎秒1 dBの変化制限を行い、残った飛び出しを追加で抑えます。ステレオでは左右に共通のカーブを適用します。

非常に小さい声や極端な音量差は、増幅上限のため完全には揃いません。ノイズ除去や無音検出は行わないため、小さい声と一緒に背景ノイズや息も目立つことがあります。

レベラーをOFFにしても、最後のラウドネス調整は実行します。「レベラーOFF・EQすべてOFF・速度1倍」は、無加工のコピーを保存する設定ではありません。

7. 3つの音声補正スイッチ

いずれも固定設定の穏やかなEQです。音源を自動分類したり、AIで声を修復したりする機能ではありません。初期OFFで、必要なものだけ選びます。複数を併用できます。

スイッチ実際の処理向いている音・注意点
低音を整理 / Tidy lows75 Hz、12 dB/octのハイパス。Qは約0.707低い振動・ゴロゴロした音を抑えます。75 Hz以下を完全に消す処理ではありません。
こもりを低減 / Reduce muddiness320 Hz中心、−2.5 dB、Q 0.8のベル型EQモワッとした厚みやこもりを軽減します。細い声では厚みが減りすぎることがあります。
明瞭さを追加 / Add clarity3.5 kHz中心、＋2 dB、Q 0.8のベル型EQ子音や言葉の輪郭を補います。鋭い声ではサ行やノイズも強まる場合があります。

Qは補正する帯域の幅を表します。Q 0.8は、中心の一点だけでなく周辺を広めに補正する設定です。低サンプルレートでは中心周波数を内部で調整します。3つともONにするほど良くなるわけではありません。

ノイズ除去、残響除去、ディエッサー（サ行だけを抑える処理）はありません。原音がすでに明瞭なら、すべてOFFのままで構いません。まず1種類だけONにして、プレビューで聞き比べると判断しやすくなります。

8. 速度と仕上がり時間

倍率の範囲は0.700～1.300倍、初期値は1.000倍です。1より大きいと速く短くなり、小さいと遅く長くなります。基本式は「仕上がり時間＝原音の時間÷倍率」です。速度変更は声の高さを保つWSOLA方式です。

1.000倍ではWSOLAの探索・重ね合わせをバイパスし、速度段はサンプルをそのまま渡します。ただし、ONにしたEQとレベラー、および最終ラウドネス調整は実行します。

「仕上がり時間」の分・秒を入力して「適用」を押すと、必要な倍率を計算します。「適用」だけでは音声を変換しません。倍率範囲外や出力72分超になる設定は使用できません。時間指定では表示倍率が小数3桁に丸まっても内部計算精度を保持します。

原音倍率仕上がりの例
60分1.00060分
60分1.20050分
60分0.900約66分40秒
60分0.700約85分43秒となるため上限超過

9. WSOLA詳細設定

通常は標準値のまま使ってください。1倍のときは速度段をバイパスし、3つの設定と初期化ボタンを無効にします。包絡比較は1倍でも使用できます。極端な設定は、音の揺れ、つなぎ目の違和感、処理時間の増加につながる場合があります。

項目標準値・入力範囲意味
処理区間の長さ / Segment length40 ms・16～120 ms音をつなぐ処理単位の長さ
接続位置の探索範囲 / Join search range±15 ms・±2～50 ms予定位置の前後で似たつなぎ目を探す範囲。端では入力範囲に制限します
つなぎの長さ / Crossfade length8 ms・2～30 ms音を重ねて滑らかにつなぐ長さ。処理区間の半分未満が必要

「標準に戻す」は、この3項目だけを戻します。速度・EQ・レベラーを初期化するボタンではありません。探索間隔と比較の間引きは画面から外し、内部で各8サンプルに固定しています。値を自動最適化するプリセットではありません。最終候補の評価は常に全サンプルです。

v0.1.3では、粗探索で複数の候補を残し、候補周辺を全サンプルで精密比較するよう改善しました。内部の間引きは粗探索だけに作用します。末尾は原音の終端に合わせた区間をつなぎ、最後の音を保持します。標準設定では最大48ミリ秒の最終区間を使います。短い音源では窓を自動で縮めます。出力全体の長さは指定倍率に合わせますが、接続位置の調整により局所的な時間対応には揺れがあります。

フォルマント分析（声の響きの比較）は、この折りたたみ内の下部にあります。v0.1.5から、発声位置を手作業で細かく探す代わりに、再生位置より先の候補を自動で探せます。

1. 「音声全体」または「30秒プレビュー」で気になる位置へ移動します。

2. 「再生位置から分析」を押します。最後に再生・シーク・再生対象の切り替えを行ったプレーヤーの位置を使い、そこから原音上の最大10秒を探索します。処理後の再生位置は原音時刻へ換算します。プレビュー欄が開いているだけでは優先しません。

3. 安定した発声候補を複数調べ、抽出した候補の中で前後の包絡の差が最も大きいものを表示します。探索範囲、候補番号、分析した窓の実際の中心時刻も表示します。

4. 分析ボタン横の「▶ 試聴」で、その箇所の周囲を聞きます。「変換前／変換後」で切り替え、「次の候補」で差の大きい順に確認できます。最後の候補の次は先頭に戻ります。

5. さらに先を調べるときは「次の10秒を探索」を押します。候補が見つからなかった区間からも進めます。音声の末尾に達するとこのボタンは無効になります。

「開始位置を指定」をONにすると、原音上の秒数を手入力できます。ボタンは「指定位置から分析」に変わります。この場合も、その位置そのものの1窓ではなく、指定位置から先の最大10秒を探索します。通常はOFFのままで使えます。

グレーはWSOLA直前（EQ・レベラー後）、水色はWSOLA直後のスペクトル包絡です。原音と最終仕上がり全体の比較ではなく、速度変換による変化を見ます。周波数軸は対数で40 Hz〜6 kHz（低サンプルレートでは上限を縮小）、縦軸は音量をそろえた相対dBです。山の横位置が重なっていれば、その発声付近の共鳴の特徴が概ね保たれていると読めます。山の幅や形も比較します。一律のゲイン差は表示から取り除きます。

探索では、約100 ms間隔で音量と周期性を確認し、無音・極小音や周期性の低い部分を除きます。その中から区間全体に分散させた最大32候補について、近接する3つの50 ms窓を比較します。変換前の音量や包絡が急変する箇所も除外します。比較帯域は主に150 Hz〜5 kHzで、弱い帯域の重みを下げ、一律の音量差を除いた包絡形状の差で順位を決めます。単発の異常値だけを最大候補にしにくいよう、3窓の差の中央値となる実際の1窓を代表として表示します。ほぼ同じ場所を繰り返さないよう、選んだ中心から約250 ms以内の候補は重複として除きます。

「抽出候補内で最大差」は、この探索範囲で実際に調べた候補の中での順位です。音声全体の最大差、すべての発声の検査、音質の悪さの判定を意味しません。探索は音声認識ではなく簡易的な選別です。声が高い、かすれている、発音が速い、背景音が多い場合などは、有効な候補が見つからないこともあります。そのときは次の区間を探索するか、別の再生位置から再試行してください。

試聴は、表示中の分析窓の中心から前後最大0.8秒、原音換算で最大1.6秒の実音を使います。変換後の長さは速度倍率に応じて変わり、音源・使用する区間の端では短くなります。前後のRMS音量をそろえ、必要に応じて両方のゲインを下げてピークを保護します。これは分析用の短い試聴だけの音量補正で、音声全体・30秒プレビュー・保存音声の音量を変更しません。

試聴バー上の水色部分が、図に使った50 msです。再生中は白い位置表示が動き、シークバーで聞き直せます。試聴ボタンは再生中「一時停止」に変わります。前後の切り替えは分析窓の中心を基準に再生位置を換算します。候補を変えると試聴を停止して、新しい候補の先頭に戻ります。分析完了時の自動再生はありません。3つのプレーヤー（全体・プレビュー・分析試聴）が同時に鳴らないようにしています。

同じ設定で全体変換済みなら、保持音声の実音と、その変換に使ったEQ・レベラー後の音を比較します。探索範囲全体が既存プレビューに収まる場合は、そのプレビューの実音を利用します。それ以外は、探索範囲の前後最大1秒を試聴用に確保し、さらに前後最大12秒をEQ・レベラー用の余白として部分処理します。通常の10秒探索で参照する原音は最大36秒の範囲です。ファイル冒頭から探索位置までを処理し直すことはありません。画面には「全体変換の実音」「30秒プレビューの実音」「選択付近を部分変換」のどれを使ったかを表示します。部分変換は全体変換の境界処理などと完全には一致しません。

比較窓は前後とも50 msです。予定倍率だけでなく、WSOLAが実際に選んだ区間の接続位置を記録して中心位置を対応付けます。画面の時刻は実際に分析した中心位置であり、候補の探索位置から少し移動する場合があります。局所的な伸縮やクロスフェードは複数位置を混ぜるため、窓内のすべてのサンプルが1対1で対応するわけではありません。部分変換時の出力時刻は全体出力に換算した目安です。

包絡線はHann窓・FFT・ケプストラムの低ケフレンシー成分（2.5 msまで、余弦で減衰）から求める平滑化推定です。F1・F2・F3の自動検出や声道の厳密な計測ではありません。ステレオは左右のパワーを平均するので、逆相で音が打ち消し合う表示にはなりません。話者が左右で異なる音源では、混ざった特徴を表示します。

無音・極小音、短すぎる区間、安定した候補がない区間では案内を表示します。末尾そのものを指定したときは少し手前へ戻してください。1倍でも分析でき、速度段を通っていないことを重ね合わせで確認できます。分析結果は固定表示で、再生中に勝手に動きません。設定変更や新しい音源の読み込みで古い比較・分析試聴は消えます。波形の位置移動だけでは、すでに分析した図はその時刻とともに残ります。包絡が重なっていても、ざらつきや接続部の違和感がないことまでは保証しません。A/B試聴と併用してください。

10. 30秒プレビューと全体変換の違い

試聴開始位置は原音上の秒数です。指定位置から原音30秒分（末尾では残りの長さ）を対象にします。Bの長さは倍率によって変わり、1.2倍なら約25秒になります。

「30秒プレビュー」を押すと区間を処理し、完成後にB（処理後）の自動再生を開始します。ブラウザに自動再生を拒否された場合は、ステータスの案内に従いプレビュー欄の再生ボタンを押してください。Aは原音、Bは処理後です。A/B切り替え時は倍率に応じて再生位置を対応させます。全体音声との同時再生は行いません。

全体変換前は、選択区間と前後最大12秒の補正用余白だけを処理します。冒頭から選択位置までの速度変換は行いません。EQなしのレベラーは読み込み時の全体解析カーブを使い、EQありでは周辺区間からカーブを作ります。ラウドネスは区間からの推定なので、全体変換後と音量・境界処理が完全には一致しません。

同じ設定で全体変換済みなら、保持した完成音声の該当部分をそのまま切り出します。この場合は全体結果と対応する音を確認できます。プレビューは全体の差分波形・測定値を更新せず、保存可能な全体音声も作りません。

平均スペクトルは、30秒プレビュー作成時に自動で表示します。原音をグレー、最終処理後を水色で重ね、横軸を周波数、縦軸を相対dBで示します。最終処理後にはEQ、レベラー、速度変換の影響がすべて含まれます。EQだけの効果の測定ではありません。

対象区間全体から均等に最大160個の40 msのHann窓を抽出し、左右チャンネルのパワーと各窓のパワーを平均します。非常に短い区間は窓も縮めます。これは区間の代表的な平均であり、全サンプルの連続スペクトルではありません。周波数方向も軽く平滑化し、40 Hz〜20 kHz（入力のナイキスト周波数以下）を対数軸で表示します。

一律の音量差を取り除いて音色を比べるため、前後のスペクトルの総パワーを合わせ、両方に共通する基準から相対dBを描画します。0 dBは表示曲線の最大値であり、音声の0 dBFSやLUFSではありません。周波数ごとに前後を一致させる操作はしないので、帯域ごとの増減は残ります。再生音・保存音は変えません。無音や極小音では比較不能の案内を表示します。位置または音声処理設定を変えるとグラフも消えるため、再びプレビューを作成してください。

11. 全体変換・やり直し・ラウドネス

全体変換は現在の設定で原音を処理し、Float32の完成音声をブラウザ内に保持します。処理順は「入力 → 音声補正 → レベラー → 速度調整 → 最終ラウドネス調整 → 保持 → 試聴／保存」です。

EQをレベラーより前に置くことで、音色補正による音量の変化も含めてレベリングします。ラウドネスは速度調整後の音で測定し、最後に全体のゲインを調整します。

−14 LUFSは目標の参考値です。K-weightingとゲーティングを使った参考Integrated LUFSから求めるゲインと、サンプルピーク−1 dBFSを守るゲインのうち、小さい方を採用します。ピークの制約で−14 LUFSまで上がらないことがあります。追加リミッターや厳密なTrue Peak制御はありません。無音は増幅せず、ラウドネスは測定不能として表示します。

音声処理の設定を変えると、以前の完成音声は無効になります。プレビューで確かめ、再び全体変換してください。出力形式だけを変えた場合は全体変換不要で、保持した音から別形式で保存できます。

12. WAV／MP3保存

形式特徴と処理
24-bit PCM WAV初期選択。非圧縮。後工程へ渡す用途にも使えます。ディザは追加しません。
16-bit PCM WAV非圧縮。保存時にTPDFディザを一度だけ追加して量子化します。
MP3・VBR Q3非可逆圧縮。音の内容に応じてビットレートが変わります。固定kbpsではありません。

16bitのディザは、ごく小さな乱数ノイズを加え、量子化の歪みをランダム化するものです。TPDFの振幅は±1 LSB（2 LSB peak-to-peak）です。ノイズ除去ではありません。同じ結果を16bitへ再保存してもディザを累積するのではなく、保持したFloat32音声から毎回作り直します。乱数のため保存ファイルは毎回完全一致しない場合があります。

MP3はBrowser Media I/O 0.5.0由来のエンコーダーで、保持した音声から直接変換します。16bit WAVを中間にしません。対応サンプルレート以外の入力はMP3保存時だけ48 kHzへ変換します。対応レートは8 / 11.025 / 12 / 16 / 22.05 / 24 / 32 / 44.1 / 48 kHzです。WAVと保持音声のサンプルレートは変更しません。

MP3にはエンコーダー遅延やパディングがあり、表示時間がWAVと厳密には一致しないことがあります。圧縮後のピークも変わる場合があり、最終ファイルのTrue Peakを保証しません。

出力ファイル名には元の名前と速度・形式などの情報を加えます。「再ダウンロード」は直前に作成したファイルを再取得します。原音は上書きしません。保存ボタンは全体変換完了後に使えます。

13. 入力形式・長さ・メモリ制限

入力はWAV／MP3、モノラル／ステレオ、8～192 kHzです。入力・出力とも最大72分です。上限を超えた部分を自動で切り捨てることはありません。

WAVは標準RIFFのPCM 8/16/24/32bit、IEEE Float 32/64bit、対応サブ形式のWAVE_FORMAT_EXTENSIBLEを扱います。原音再生はブラウザのデコーダーに依存するため、読み込める特殊なWAVでも再生できないことがあります。

完成音声のFloat32換算容量は1.75 GiBまでです。72分・48 kHz・ステレオはこの枠に収まりますが、高サンプルレートでは72分未満でも容量制限に達します。計算式は「秒数×サンプルレート×チャンネル数×4バイト」です。

MP3入力は圧縮ファイル128 MiB、デコード済みPCM512 MiBまでです。ブラウザが全体をデコードするので、長さ制限内でもメモリが不足することがあります。デコード後の容量判定より前にもメモリ確保が必要です。大きなMP3はあらかじめWAVに変換してから読み込んでください。

WAVは小分けに読み込みますが、完成音声と保存用ファイルを保持する領域、ブラウザの再生用領域などは必要です。上限内であっても、すべての端末で成功する保証ではありません。

14. 困ったとき

状況確認・対処
処理後を選べない／保存できない30秒プレビューだけでは全体音声は完成していません。「全体変換」を実行してください。設定変更後も再変換が必要です。
プレビューが自動再生しないブラウザの自動再生制限や音声出力設定を確認し、プレビュー欄の再生ボタンを押してください。
プレビューと全体結果の音量が違う全体変換前は区間からの推定です。同じ設定で全体変換した後のプレビューで確認してください。
1倍でも音が変わる速度変換はバイパスしますが、EQ・レベラー・最終ラウドネス調整はそれぞれ働きます。
−14 LUFSにならないサンプルピーク制約を優先しています。厳密な到達を保証する仕様ではありません。
声が細い／サ行が強いこもり低減／明瞭さ追加をOFFにして比較してください。
背景ノイズが目立つレベラーが小さい声と一緒にノイズも持ち上げる場合があります。ノイズ除去は別の処理が必要です。
メモリ不足・長さエラー仕上がり72分以下を確認し、不要なタブを閉じる、音源を分割する、MP3をWAVへ変換するなどを検討してください。
ダウンロード先が分からないブラウザのダウンロード一覧と保存設定を確認してください。
再読み込み後に結果が消えたセッションの自動保存はありません。元の音を読み込み直して変換してください。

15. 用語とライセンス

LUFSは聴感を考慮した音量の指標、dBFSはデジタル信号の最大値を基準にしたレベルです。サンプルピークは記録されたサンプルの最大値、True Peakはサンプル間の再構成波形も考慮したピークです。両者は同じではありません。PCMは非圧縮のサンプル列、WSOLAは似た波形を探して重ね合わせ、声の高さを保ちながら時間を伸縮する方式です。
